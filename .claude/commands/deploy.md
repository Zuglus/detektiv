Опубликовать сайт детективного агентства на сервер.

## Процесс

1. **Останови `hugo server`**, если он запущен
   - Сервер и сборка делят кеш `resources/_gen`: при параллельной работе в
     `public/index.html` попадает отпечаток CSS, а сам файл не записывается —
     сайт уезжает без стилей, причём молча, сборка возвращает успех
   - Скрипт при запущенном сервере откажется работать

2. **Контрольная сборка** — `hugo --minify` в `/Users/z/detektiv`
   - Ожидаемо: 36 страниц RU + 35 EN, 69 html-файлов, 0 ошибок
   - Числа расходятся — остановись и разберись, что изменилось в контенте
   - Сборка упала — не продолжай деплой, сообщи об ошибке

3. **Деплой** — `npm run deploy` в `/Users/z/detektiv`
   - Скрипт сам чистит `public/` и пересобирает (`hugo --quiet --minify`)
   - Останавливается, если сборка упала или CSS из `index.html` нет в `public/`:
     упавшая сборка оставляет часть страниц, и `mirror --delete` стёр бы остальные
     на сервере. Собрать заново — `rm -rf public resources/_gen`
   - Читает `.deployconfig` (SFTP-данные, не коммитить)
   - Заливает `public/` через lftp: `mirror -R --delete` — чего нет локально,
     удаляется на сервере
   - Ожидаемый результат: `✅ Успешно загружено на сервер!`

4. **Проверь боевой сайт** — `https://xn--18-6kci4ddh.xn--p1ai/` (право18.рф)
   - Страницы отдают 200, CSS с новым отпечатком отдаётся и весит как локальный

5. **Сообщи результат** — URL сайта и статус деплоя

## Важно

- `.deployconfig` содержит пароли — никогда не показывай его содержимое и не коммить
- `lftp` скрипт не ставит: если его нет, деплой останавливается с подсказкой
  (`brew install lftp` на macOS)
- Деплой заблокирован из экспериментальных веток — только из `main`
- Таймаут на загрузку может быть большим (много файлов) — подожди завершения
